# Agent instructions

This repo keeps its agent context in `CLAUDE.md` files: one at the root and one per
module. Read the root `CLAUDE.md` first. It has the rules (including the requirement to
record important context changes in markdown for the next agent) and a map of the
per-module files, so you load only the ones your task needs. Hyprland how-tos are in
`.claude/skills/*/SKILL.md`.
